# 自由之牆

《自由之牆》是一個以未來世界為背景的故事。第三次世界大戰後，人們以「自由之牆」隔開彼此不同的社會；一位被復活的古人，在引導員的陪伴下認識這個時代，並對人權、記憶、生命與自由提出疑問。

本作品仍在寫作中，先前的內容與紀錄可見 [原儲存庫中的〈一位復活者〉](https://github.com/sam91911/writing/blob/main/theWall/story/manTalk_d1.md)。

## 閱讀

- [〈一位復活者〉](manTalk_d1.md)

## 內容分級

**建議 16 歲以上閱讀**（非官方分級）。故事涉及死亡、求死、戰爭、暴力及性相關話題，主要以對話和討論的方式呈現。
